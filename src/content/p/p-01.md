Timebox is a countdown timer that does one thing. You type a number of minutes, press start, and the time left shows in the browser tab’s title, so you can see it without switching back to the page.

I made it because every timer I found had sounds, themes and accounts, and I only wanted to know when twenty minutes were up. It is a single page with no sign-in and nothing saved on a server.

I have put it on hold. It does what I need, and the only things left to add are things I don’t want, such as history and statistics. If it ever breaks in a new browser, I’ll fix it.
