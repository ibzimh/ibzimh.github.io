Tinylog is a small command line program for keeping a journal. You type a line, and it appends that line to a text file with the date and time in front. That is the whole feature set.

It grew out of my work log. I was already writing to a text file by hand, and opening the file, scrolling to the bottom and typing the date was enough friction that I skipped days. Now it is one command from wherever I happen to be in the terminal.

The file is plain text on purpose. I can search it with any tool, back it up by copying it, and read it in twenty years without Tinylog. The program reads the file only to show the last few entries.

I use it every day and still change small things as I notice them.
