For about a year now I have kept a work log. It is one plain text file. Each day I add a line with the date and a few words about what I did, what I got stuck on, and what I want to do next.

I started because I kept forgetting where I had left things on a Friday. On Monday I would spend the first half hour trying to remember. Now I read the last few lines of the file and I am back in it within a minute.

It turned out to be useful in other ways too. When someone asks how long something took, I can look it up instead of guessing. When a bug comes back, I can search the file for the last time I saw it. And when I feel like I got nothing done, I can scroll up and see that I did.

The rule that keeps it going is that it has to cost almost nothing. No template, no tags, no tool to open. If writing an entry ever feels like a chore, I write less, not nothing.
